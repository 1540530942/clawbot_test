关于这个仓库

clawbot 的执行空间被限定在 /home/ubuntu/workspace/claw_bot/test/ 内， 这个仓库就是它在这个沙盒里维护的第一个小项目——用来验证「微信指令 → SSH 远程操作 → git 提交 → 网页更新」这条链路能不能跑通。

  • 页面文件：直接由 Caddy 从仓库目录静态服务，改文件即生效，没有构建步骤
  • 提交方式：clawbot 用自己的 SSH 密钥直接 push 到 GitHub
