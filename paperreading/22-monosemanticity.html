这篇论文在说什么

大模型是怎么“想”的？模型里全是数字。把一个小模型的某个神经元（模型里最小的计算单元）拿出来看，你可能会发现它对学术引用、英文对话、HTTP 请求和韩文都有反应。这些东西八竿子打不着，它到底代表什么？

2023 年，Anthropic 的这篇论文给了一个看法：单个神经元不是好的观察单位，真正有意义的是藏在它们里面的“特征”。他们用稀疏自编码器，从一层 512 个神经元里挖出了几千个清晰的特征，比如“这段字是阿拉伯文”“这是 DNA 序列”。这是理解 AI 内部运作的一大步。

提前说明：这篇论文也来自 Anthropic，也就是开发我的公司。下面的内容来自论文本身。

旧方法的问题：一个神经元身兼多职

这种现象叫多义性（polysemantic）：一个神经元对多种不相关的东西都有反应。图像模型 Inception v1 里也有一个神经元，既对猫脸有反应，又对汽车正面有反应。

生活中的类比

一个小公司里，王阿姨同时管财务、前台、采购和保洁。你看她在忙，却猜不出公司这会儿在发生什么。如果给她做一张工作记录表，把每件事写清楚，就明白多了。论文要做的就是这张表。

为什么模型要这样？论文的解释是“叠加”假设：世界上的概念太多，神经元不够用，模型就让很多概念共用神经元。

动手试试：打开几个概念，看神经元的值怎么混在一起

这个小模型有 5 个概念，只有 2 个神经元。点按钮打开或关闭概念。只有一个概念时，还能猜出是哪个；打开两三个，就开始混淆了。这就是为什么概念必须很稀疏。

核心思想：用稀疏自编码器拆开

既然概念混在一起，能不能拆开？这就是稀疏自编码器要做的事：把 512 个混在一起的数字，展开到很多个“格子”，要求每次只亮很少几个格子。

它要同时做到两件事：

  • 还原得准：只用亮着的格子，就能算回原来的 512 个数。
  • 亮得少：每次亮的格子越少越好。

为什么要求“亮得少”？因为真实世界里，一段话只涉及很少几个概念。如果每个格子代表一个概念，亮的格子自然应该很少。这就把拆概念变成了一个可以算的问题。

数学：损失函数的两部分

第一步，把每个格子的值叫 f，还原公式是加权和：

x̂ = f₁·d₁ + f₂·d₂ + … + fm·dm
x
原来 512 个神经元的值。
x̂
还原出来的值，读作 x 帽。
fi
第 i 个特征亮多少，等于 0 就是没亮。
di
第 i 个特征对应的方向，也就是图 1 里的箭头。

第二步，写下要最小化的损失：

损失 = ‖x − x̂‖² + λ · ( |f₁| + |f₂| + … + |fm| )
‖x − x̂‖²
L2 还原误差：还原值和真实值的差，平方后加起来。
|fi|
绝对值。全部加起来叫 L1。亮得越多越大。
λ
一个系数，决定有多看重“亮得少”。
两种还原方案比一比，λ = 0.5
  1. 真实 x = (1, 0)
  2. 方案 A：只亮一个 f₁ = 1，方向 d₁ = (1, 0)，x̂ = (1, 0)，误差 0，L1 = 1，损失 = 0 + 0.5×1 = 0.5
  3. 方案 B：亮 f₁ = 0.6 和 f₂ = 0.6，方向 d₁ = (0.8, 0.6)，d₂ = (0.8, −0.6)。x̂ = (0.96, 0)，误差 = 0.04² = 0.0016，L1 = 1.2，损失 ≈ 0.0016 + 0.6 = 0.6016
  4. 两个方案都能还原得不错，但方案 A 亮得少，损失更低。L1 就是这样把模型推向“一件事只亮一个格子”。

我训练了一个玩具版来验证

我用图 1 的设定实际训练了一个小的稀疏自编码器：5 个真实方向、2 个神经元、12 个格子，每个概念只有 10% 的时候出现。模型不知道真实方向，只看到两个混在一起的数。结果：

还原误差从不还原时的 0.154 降到 0.0006。不过也不是完美的：第 5 个方向相似度只有 0.829，而且每次平均亮 0.90 个格子（这里只统计亮度明显大于 0 的），实际出现的概念平均是 0.49 个。这说明这类方法并不保证找回全部概念。这和论文提到的“挖掘特征不完美”是一致的。

实际效果

论文的模型很小：一层 Transformer，512 个神经元，在 1000 亿 token 的 The Pile 上训练。稀疏自编码器用了 80 亿个神经元值样本，展开倍数从 1 倍（512 个特征）到 256 倍（131,072 个特征）。详细分析的是 8 倍的 A/1，共 4096 个特征。

最后一行很关键：希伯来文这个特征，从神经元出发根本看不出来。这说明这种方法确实看到了新东西。

论文还有这些结果：

  • 特征比神经元好懂：人工评分和自动评分都明显高于神经元。
  • 能控制模型：强行点亮某特征，模型的行为会按预期改变。这说明特征真的和模型的工作方式有关，不只是我们想象出来的。
  • 有一定通用性：不同模型里能找到相似的特征。
  • 分辨率可调：格子少时看到粗略的概念，格子多时一个概念会分裂成细节，这叫“特征分裂”。

影响和局限

影响：一年后，同样的方法被用到大模型 Claude 3 Sonnet 上，找出了千万级的特征，那个著名的“金门大桥”特征就是这样来的。OpenAI、Google 也发表了类似研究。这让“看懂大模型”不再只是空想，也关系到将来如何检查模型是否在说谎。

局限：

  • 模型极小。论文只有一层，当时还不知道能否推广到大模型。
  • 训练细节多。有些格子会“死掉”（再也不亮），要定期重置。
  • 叠加只是假设。它能解释很多现象，但不是定论。
  • 解释是人给的标签。说某特征是“阿拉伯文”，只是人根据观察起的名字，不能保证它没有其他作用。
  • 还没解决“怎么算的”。找到零件，不等于搞清楚它们如何协作。

和你的机器人的关系：这篇对你不是马上能用的工具。但思路值得记住：要调试一个 VLA 模型为什么撞墙，以后也许能查到“障碍物”的内部特征，甚至直接干预它。这目前还只是研究方向。

一句话总结：一个神经元身兼多职，用稀疏自编码器把它们拆开，大模型的“大脑”才第一次露出能看懂的零件。
