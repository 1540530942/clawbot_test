世界模型：在梦里学开车World Models

打棒球时，球的信号传到大脑之前你已经挥棒了，因为大脑在预测。这篇论文照此搭了一个智能体：一个大的“世界模型”压缩所见并预测未来，一个只有几百个参数的小控制器做决定。世界模型不看奖励，只负责理解世界。更妙的是，控制器可以完全在世界模型生成的“梦”里训练，再搬回真实环境。

棒球手的直觉

来不及想的那一瞬间

一颗 160 公里每小时的球，从投手到本垒不到半秒。信号传到大脑还要时间。击球手不是看到球才决定，而是大脑早就预测好了，肌肉直接行动。

论文用这个例子说：我们看到的是大脑对世界的预测，决定建立在这个预测上。所以智能体也可以分成两部分：理解世界和预测的大模型，凭直觉决策的小模型。这个例子是论文 §1 的。

三件套：V、M、C

把复杂度分开：V 和 M 很大，但可以用反向传播和 GPU 高效训练，完全不看奖励。C 很小，只看 z 和 h，用无梯度的方法优化。这样避开了强化学习难以把奖励归因到几百万参数的问题。

867 怎么来
  1. 输入 z（32）和 h（256），共 288 维。
  2. 输出 3 个动作：转向、油门、刹车。权重 288 × 3 = 864。
  3. 偏置 3 个。合计 867。
  4. VizDoom：64 + 1024（c 和 h）= 1088，1 个动作，没有偏置，1088。

V：把画面压成 z

V 是卷积 VAE。图缩放到 64×64×3，压成 z ∈ R³²（Doom 用 64）。

L = ‖x − x̂‖² + DKL( N(μ, σ²I) ‖ N(0, I) )，　z = μ + σ ε

KL 项把 z 压向标准高斯，不只是省信息，也让模型对 M 生成的不真实 z 更稳健。局限也很明显：它不知道什么重要，Doom 里能精细重建墙砖，赛车里却漏掉了路面的格子。

M：预测下一个 z 的分布

M 是 LSTM 加混合密度网络。世界是随机的，所以预测分布，不是一个数：

P(zt+1 | at, zt, ht) = Σk=15 πk N(μk, σk²)，　温度 τ：π ← softmax(log π / τ)，σ ← σ√τ
为什么要混合
  1. 怪物要么发火球，要么不发，这是离散事件。
  2. 如果只有一个高斯，模型只能预测中间值，比如“半个火球”。
  3. 两个成分：有火球 z ≈ 2，无火球 z ≈ −2，概率 0.3 和 0.7。采样时就是一个清楚的结果。
  4. τ 变小（0.1），几乎总是选 0.7 的“无火球”。这个模型就没有火球了，后面会看到后果。
动手玩：温度如何改变预测

π = (0.3, 0.7)。拖动 τ，看选择概率和每个成分的宽度。

训练时喂的是预先算好的 μ、σ 再采样，防止过拟合到某一次 z。

C：一层线性 + 演化策略

at = Wc [zt, ht] + bc

这里 ht 里有“未来”的信息。不用规划，只查询即可，很像棒球手的直觉。优化用 CMA-ES：每代 64 个候选，每个跑 16 次，取平均奖励。不需要梯度，也容易并行。

CMA-ES 的基本想法（简化）
  1. 从高斯分布里抽 64 组权重。
  2. 每组玩 16 局，算平均分。
  3. 留下好的，更新分布的均值和协方差。
  4. 重复。下面的迷你实验用了更简单的对角 CEM。

赛车实验

  • 流程：随机策略收集 1 万局 → 训 V → 训 M → 用 CMA-ES 训 C。V 和 M 每个不到一小时单 GPU。
  • 只有 z：632 ± 251，车摇摆，转弯会丢。加一个隐藏层 788 ± 141。
  • z + h：906 ± 21。论文说是第一个解开（100 局平均 ≥ 900）的方法。
  • 梦：可以把学好的 C 放回 M 的幻觉中。

在梦里练：躲火球

VizDoom: Take Cover。躲避火球，活得越久分越高，到 2100 步结束，平均超过 750 步算解开。这次 M 还要预测是否死亡（超过 50% 就算死），有了它，M 就是一个完整的环境。

  1. 随机策略收集 1 万局。训 V（z = 64）、训 M（LSTM 512，5 个成分）。
  2. 把 M 包成 gym 环境。C 只在里面练。甚至不用 V，不渲染画面，只有潜向量。
  3. 到真实 VizDoom 里测：≈1100 步，远高于 750，也高于梦里的成绩。

有趣的现象：M 学到了游戏规则（左转会动，撞墙不会穿），还能跟踪多个火球。虽然怪物数量都不对，但能活下来就够了。这就是“梦里更难，真实反而轻松”。

温度和“作弊”

C 在梦里能接触 M 的所有隐藏状态，所以能找到漏洞。早期实验中，控制器学会一种动作，让火球自动熄灭：现实里根本不存在。这和小时候找游戏秘籍很像。

怎么读这张表
  1. τ = 0.1：梦里 2086 接近满分，现实 193，比随机还差。低温模型根本不发火球（模式坍塌），控制器什么也没学到。
  2. τ = 1.15：梦里 918，现实 1092。这里最好。
  3. τ = 1.3：梦里 732，现实 753，分低但方差小。
  4. 梦里分高不代表好。需要一个难度合适的梦。

这是论文最有启发的结论：噪声是防止钻模型空子的工具。论文也讨论了为什么以前很少完全用世界模型替代环境：确定性模型容易被利用；用贝叶斯模型（如 PILCO）能缓解，但不能完全解决。

迭代训练

本文的任务简单，随机策略就够。复杂任务要反复：

  1. 随机初始化 M、C。
  2. 在真实环境玩 N 次，保存数据。
  3. 训练 M 预测 P(x, r, a, d | x, a, h)；在 M 中训练 C。
  4. 没解决就回到 2。

论文也提议把 M 的损失翻转当好奇心奖励，鼓励去预测不准的地方。这部分只是提议，没有实验。它还把这和海马体回放联系起来。

读结果时要注意的地方

  • 赛车的 C 不省交互：64 × 16 × 1800 代 ≈ 184 万局真实环境。世界模型的价值是表示，不是减少样本。这个数是我们按附录算的。
  • “完全在梦里”的前提：V、M 用了 1 万局真实随机数据；τ 在表 2 里是对照真实成绩选的。如果不能接触真实环境，就不知道该选 τ。
  • 方差很大：1092 ± 556，而 τ = 1.0 是 868 ± 511。这些差距看起来未必稳定。
  • 数字差异：附录说 τ = 1.15 的最好智能体 1024 局平均 959（梦里），表 2 同一设置虚拟分是 918。评估局数不同，也可能是不同的代。
  • 比较对象：对比项有 Gym 排行榜、博客和论文，不同实现、不同训练预算，不是受控比较。“第一个解开”也限定在“已知”。
  • 任务简单：论文自己说，随机策略就够是因为任务简单。
  • 重大提议未验证：§5 的迭代流程和好奇心都未实验。

亲手试：看它做梦

我们写了一个“躲火球”小游戏（8×9 像素，火球下落，底部的人左右移动，世界左右相接）。观测以自己为中心，就像 CarRacing 的摄像头跟着车走，所以人永远在画面底部正中（绿框），流程和论文一样：随机策略收集 800 局 → MLP-VAE（z = 12）→ LSTM + 3 成分混合密度网络（手写反向传播，和数值微分对比过）→ 线性控制器。用对角 CEM 代替 CMA-ES：每代 32 个候选、每个 6 局、40 代。全部在 CPU 上。这是玩具。完整脚本在这里。

这组结果怎么读（诚实版）：
  • 这个实验跑了三轮才像样：第一轮 NaN：训练窗口共用起点，整批都已死亡时除以 0，权重全坏了，我中途停掉。第二轮修好后，连直接在真实环境训练的控制器也只活 53 步，随机策略约 39 步。诊断发现 VAE 记住了人在哪，却只留住 14% 的火球，靠近底部几乎是 0%，因为 β 太大，把稀疏的亮点当噪声丢了。手写的躲避规则却能活满 300 步。而且人位置可变时，“火球在我头上”是个乘积，线性控制器表达不了。于是我改成以自己为中心的视角，把 β 从 0.5 降到 0.05，火球召回升到约 84%。这恰好说明 V 为什么重要：控制器再好，也只能用表示里留下的信息。三轮的记录都在存档里。
  • 论文最有意思的现象出现了：τ = 0.1 时，两个种子在梦里都活满 300 步，一到真实环境只有 26 和 42 步，比随机（约 36 步）还差或差不多。我的猜测是低温的梦里死亡和火球都很少，控制器钻了这个空子（没有逐帧检查）。这和论文表 2 里 τ = 0.1 时虚拟 2086、真实 193 是同一回事。
  • τ 升高，梦变难，迁移变好（种子 0）：τ = 1.0 时梦里只有 58 步，真实却有 155 步，约为随机的 4 倍。这也和论文相似：合适温度下真实分可以高于虚拟分。
  • 但种子 1 迁移得差得多：它的真实分最高只有 τ = 1.5 的 62 步，其余都接近随机。上面的表是平均数，会把这个差别藏起来，请不要只看平均。原因我没有查清。两个种子不足以说明“从梦到现实”有多稳定，只能说它可以成功，也可以失败。论文表 2 的方差也很大（1092 ± 556）。
  • 直接在真实环境训练仍然更好：同样的代数，z + h 是 297 和 159 步，只给 z 是 287 和 142 步。这里 h 带来的提升不大，可能因为躲火球只需要看当前画面，不怎么需要记忆。这和 CarRacing 里 z + h 明显更好不同。真实训练的代价是要在真实环境里玩 7680 局，梦里训练一局真实游戏也不用，只用了收集数据的 800 局随机游戏。
  • 规模：2 个种子，CEM 40 代，VAE 和控制器都很小，游戏也是我写的。这是玩具，不代表论文的具体数字。下面的小组件用的是种子 0 在 τ = 1.2 训练的控制器（真实平均 143 步，波动很大）。

局限和争议

  • VAE 不知道重要什么：无监督，可能漏掉任务相关内容。一起训练 M 的奖励预测可能好一点，但复用性变差。
  • M 容量有限：会灾难性遗忘。
  • 一步步模拟：没有层次规划。
  • 归因：很多想法源自早年工作。论文也花了不少篇幅强调这个历史；引用评价和归属是长期争议（背景知识）。
