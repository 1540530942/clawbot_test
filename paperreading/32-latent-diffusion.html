潜扩散：把画画搬到草稿纸上High-Resolution Image Synthesis with Latent Diffusion Models

DDPM 直接在像素上工作，最强的模型要花几百个 GPU 天。这篇论文的思路是：图片的大部分比特是人看不出的细节，先压掉；在压缩后的小空间里做扩散，最后再一次解码回来。加上交叉注意力，还能接受文字等任意条件。这就是 Stable Diffusion 的基础。

先压缩再创作

在草稿纸上画

画家要画一张巨幅壁画。如果每改一笔都要爬到墙上，一幅画要好几年。聪明的做法是先在小草稿上反复推敲构图和内容，定稿后再放大上墙。放大这一步是机械的，不需要创意。

LDM 里的“放大师傅”是解码器，训练一次就能反复用。创作在草稿上进行。这个比喻是我们编的，它隐含一个前提：放大师傅必须能把草稿还原得几乎和真图一样。

两种压缩

论文图 2 用 DDPM 的码率—失真曲线（上一期）说明：扩散模型开始时只用很少的比特就把失真压得很低，之后大量比特花在几乎看不出的地方。

  • 感知压缩：去掉人看不出的细节。这一步可以由自编码器单独做，只需一次解码。
  • 语义压缩：学内容和结构。这才需要生成模型。

扩散模型的权重虽然压低了这些细节项的损失，但网络还是要在每个像素上算。LDM 直接把这个开销也省了。

第一步：自编码器

z = E(x)，　x̃ = D(z)，　f = H / h = W / w（f = 2m）

x ∈ RH×W×3，z ∈ Rh×w×c。关键是 z 保留二维结构。此前 VQGAN、DALL-E 把 z 拉成一维序列给 Transformer，所以必须压得很狠。这里的扩散模型用卷积，可以用很轻的压缩。

L = minE,D maxψ ( Lrec(x, D(E(x))) − Ladv(D(E(x))) + log Dψ(x) + Lreg )
Lrec
感知损失（LPIPS）加像素损失。
Ladv
图块判别器，避免模糊。
Lreg
防止潜空间方差太大。两种：KL 权重约 10⁻⁶（非常小）；或者向量量化，码本放在解码器里。
算一下压缩量（512×512 彩色图，f = 8，c = 4）
  1. 像素：512 × 512 × 3 = 786,432 个数。
  2. 潜变量：64 × 64 × 4 = 16,384 个数。
  3. 压缩 48 倍。每个去噪步的卷积运算量大约也减少这么多（我们的粗算，实际还取决于通道数）。

图 1 的例子中，f = 4 时 PSNR 27.4、R-FID 0.58；DALL-E 的 f = 8 是 22.8、32.01；VQGAN 的 f = 16 是 19.9、4.98。这三组数字都来自论文图 1。

第二步：潜空间扩散

LLDM = EE(x), ε, t[ ‖ε − εθ(zt, t)‖² ]

和 DDPM 的 Lsimple 一模一样，只是把 x 换成 z。生成时采样 z₀，再一次通过 D。附录 B 用信噪比把这和 ELBO 联系起来，形式和第 31 期相同。

缩放很重要：KL 正则很弱，所以 z 的方差可能很大，相当于信噪比很高。论文把 z 除以第一批数据的标准差。这个看似小的操作，明显影响大图卷积采样的效果（附录 D.1）。VQ 空间方差接近 1，不用缩放。

交叉注意力和条件

文字、框等输入先由各自的编码器 τθ 变成一串向量，然后在 U-Net 的多层上做交叉注意力：

Attention(Q, K, V) = softmax(Q KT / √d) V Q = WQ φi(zt)，　K = WK τθ(y)，　V = WV τθ(y) LLDM = E[ ‖ε − εθ(zt, t, τθ(y))‖² ]
算一下：图片的一个位置去问文字
  1. 假设文字有两个词：“红”“猫”，它们的 K = (1, 0)、(0, 1)。V = (10, 0)、(0, 10)。
  2. 图片某处的 Q = (2, 0.5)，d = 2。打分：Q·K/√2 = 1.41、0.35。
  3. softmax：0.74、0.26。
  4. 输出 = 0.74 × (10, 0) + 0.26 × (0, 10) = (7.4, 2.6)。这一处主要听“红”的。
  5. Q 来自图片，K、V 来自文字。图片提问，文字回答。

τθ 和 εθ 一起训练。对于分割图这样空间对齐的条件，可以简单地把它和 z 拼接，然后在大图上卷积采样（§4.3.2）。

无分类器引导

第 2 版加入了 Ho、Salimans 的方法：训练时随机丢掉条件，采样时外推。公式来自那篇论文，LDM 只是使用它（表中的 s）：

ε̂ = εθ(zt, ∅) + s · ( εθ(zt, y) − εθ(zt, ∅) )
s 做了什么
  1. s = 1 就是普通的条件模型。
  2. 无条件预测是 0.2，条件预测是 0.5，s = 3：0.2 + 3 × 0.3 = 1.1。
  3. 把“加了条件后的变化”放大。太大会失真。FID 表用 s = 1.5，图 5 展示图用 s = 10。

该压缩多少

论文固定一块 A100，同样步数、同样参数量，比较 f = 1, 2, 4, 8, 16, 32（§4.1）。

  • f = 1、2：进步慢。感知压缩留给了扩散模型。
  • f = 32：很快停滞。第一阶段丢了太多信息。
  • f = 4–16：平衡。LDM-8 和像素 LDM-1 在 200 万步后 FID 差 38。
  • 图 7：复杂的 ImageNet 要轻一点的压缩。总结是 f = 4、8 最好。

读结果时要注意的地方

  • “新 SOTA”的范围：无条件上只有 CelebA-HQ 的 5.11 是最好的。FFHQ（4.98 对 3.08）、Churches（4.02 对 1.59）、Bedrooms（2.95 对 1.52）都输 ProjectedGAN；Bedrooms 还输 ADM（1.90）。论文的 P&R 确实更好。
  • 文本“on par”：12.63 略差于 GLIDE 12.24 和 Make-A-Scene 11.84，对比数字来自别的论文，FID 实现可能不同。参数少确实是优势。
  • 展示图 s = 10，表用 s = 1.5：好看的图和好看的 FID 不是同一个设置。
  • 超分的两种 FID：LDM-4 是 2.8†（验证集特征）和 4.8‡（训练集特征）。和 SR3 的 5.2 比，应看 ‡。IS 输，PSNR、SSIM 都输。用户研究也只和像素基线比，没和 SR3 比。
  • 修补的 SOTA：9.39 靠 big 模型在 512 分辨率上微调。普通 LDM-4 的 11.87 输 CoModGAN 的 10.4，LPIPS 略差于 LaMa（0.246 对 0.243）。
  • FID 样本数：图 7 只用 5000 个样本，小于常用的 5 万。
  • 算力对比：V100 天是由 A100 乘 2.2 换算的，而且对手数字来自 ADM 论文。第一阶段（f = 4 约 29 天）在“总算力”里算不算要看表（表 18 列在单独行）。
  • 版本变化：附录 A 说第 2 版换了更大的文本模型和 ImageNet 模型，也加了引导。早期引用的数字可能和这里不同。
  • “for the first time”：摘要说第一次达到近乎最优的平衡点，这是作者的表述，没有定量定义。

亲手试：压缩多少才好

我们用 NumPy 写了最小的版本：16×16 字形图（256 维），MLP 自编码器压到 z = 64、32、16、8、4 维，再在 z 上训练条件扩散，训练同样步数，和直接在 256 维像素上做扩散比较（像素版第一轮 128 单元发散，又用 512 单元补跑了一轮）。条件用独热向量拼接，没有实现交叉注意力，也没有对抗损失和卷积，所以看不到论文说的二维结构优势。随机 10% 丢条件，支持引导。评分用我们自己训练的分类器（精度 100%）算准确率和“类 FID”。2 个种子。这是玩具。第一轮脚本和像素加宽版脚本都可以下载。

MSE 是自编码器重建误差；步耗是训练每步毫秒数；采样 s 是生成 800 张的秒数；FID 是类 FID。

这组结果怎么读（诚实版）：
  • 第一轮的“像素版完败”不能当结论。128 单元的像素版准确率 10%，等于瞎猜，类 FID 约 2800 万，已经完全发散。但它要从 128 个单元输出 256 维噪声，而潜空间版的输出维度都不超过 128。我们猜是宽度害的，于是把像素版加宽到 512 单元，让“单元数 ÷ 维度”等于 2，和 z = 64（128 ÷ 64）一样。
  • 加宽后不再发散，质量也追上来了。512 单元的像素版，s = 1 时准确率 36%、类 FID 58；同样宽度比的 z = 64 是 25%、58。所以在这个玩具里，像素空间本身并不差。
  • 差的是价钱，这正是论文的核心。要达到同样的宽度比，像素版每步的参数乘法约 81 万次，z = 64 约 5.5 万次，差 15 倍；实测每步 625 毫秒对 79 毫秒，差 8 倍；采样 800 张 205 秒对 15 秒。这里还没算上训练自编码器的费用，论文里第一阶段也只训一次。
  • 压缩有个合适的度。128 单元下，从 z = 64 压到 z = 8，s = 1 的准确率从 25% 升到 56%，类 FID 从 58 降到 21；压到 z = 4 就变差（35%、43），自编码器的 MSE 也从 0.047 涨到 0.138。形状和论文“压太少慢、压太多丢细节”相似。但有干扰：所有潜空间版都用 128 单元，z 越小宽度比越大，所以中间的改善不能全算到压缩头上。
  • 引导在这里是把双刃剑。s 从 1 到 3，准确率都涨（z = 16 从 52% 到 82%），但类 FID 大幅变差（31 到 385）；s = 7.5 时更是上千，512 单元的像素版在 s = 3 时也到了 1498。论文里 s = 1.5 是改善 FID 的。我们的类 FID 算在分类器特征上，又没有截断，可能夸大了这个差距，这一点没有再验证。
  • “缩放潜变量”这招在这里没帮上忙。论文把 KL 潜变量除以标准差再扩散。z = 16 不缩放反而略好（57% 对 52%），类 FID 27 对 31。我们的潜变量标准差约 1.4，本来就离 1 不远（这个解释是猜测）。
  • 看不到的东西。这里没有卷积、交叉注意力和对抗损失，也就测不到论文说的“保留二维结构”和文本条件。像素版只测了 s = 1 和 3 两档。

局限和社会影响

§5 论文自己写的：

  • 慢：序贯采样仍然比 GAN 慢。
  • 高精度任务：f = 4 的重建误差可能成为瓶颈，超分已经有所体现。
  • 深度伪造：论文明确指出女性受影响尤其严重。
  • 泄露训练数据：生成模型可能泄露未经同意收集的数据。
  • 偏见：会复制和放大数据中的偏见。

此外，LAION 这样从互联网收集的训练数据引发了版权和不当内容争议（背景知识）。

一页总结

  • 一个观察：大部分比特是看不出的细节。
  • 两步：训自编码器；在 z 上做扩散。
  • 一个机制：交叉注意力，图片提问，条件回答。
  • 一个数字：f = 4 或 8。
  • 一个提醒：“新 SOTA”只在部分数据集上成立。
