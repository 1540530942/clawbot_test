DDPM：把噪声一步步擦成图片Denoising Diffusion Probabilistic Models

往清水里滴一滴墨，它会慢慢散开。这个过程容易，倒过来很难。扩散模型的想法是：如果每一步只散开一点点，那么倒退一小步也是可以学的。这个想法 2015 年就有了，但一直没生成出好图。这篇论文找到了正确的写法：让网络预测噪声，训练目标简单到只有一行。它是今天 AI 绘画的起点。

修复一张被污染的画

一千次很小的修复

一位修复师面前的画满是斑点。如果让他一次复原，几乎不可能。但如果每次只让他猜：“这些斑点里，最近加上去的那一小点是什么样？”然后擦掉，这件事就简单很多。

训练他很容易：拿一张好画，自己撒一层已知的斑点，让他猜刚撒的斑点。因为答案我们知道，所以可以批改。练好后，给他一张纯噪声，让他擦 1000 次，就会有一张从来没有过的画。比喻是我们编的。

前向：加噪声

q(xt | xt−1) = N(xt; √(1 − βt) xt−1, βt I)
x₀
原图，像素缩放到 −1 到 1。
βt
第 t 步噪声的方差。论文从 0.0001 线性增加到 0.02，共 T = 1000 步。
√(1 − βt)
先把信号缩小一点，这样加噪后总方差不会变大（如果原来是 1，(1 − β) + β = 1）。

最有用的性质是可以一步跳到任意 t。记 αt = 1 − βt，ᾱt = α₁α₂…αt：

xt = √ᾱt x₀ + √(1 − ᾱt) ε，　ε ~ N(0, I)
验证两步合一步
  1. x₁ = √α₁ x₀ + √β₁ ε₁。
  2. x₂ = √α₂ x₁ + √β₂ ε₂ = √(α₁α₂) x₀ + √α₂√β₁ ε₁ + √β₂ ε₂。
  3. 两个独立高斯相加，方差相加：α₂β₁ + β₂ = α₂(1 − α₁) + 1 − α₂ = 1 − α₁α₂。
  4. 所以 x₂ = √ᾱ₂ x₀ + √(1 − ᾱ₂) ε。依此类推。
动手玩：信号还剩多少

这是论文的噪声表（β 从 10⁻⁴ 到 0.02，T = 1000）。拖动 t 看 √ᾱ。下面的格子把一个“1”按这个比例加噪。

目标：变分下界

反向过程是可学的高斯：pθ(xt−1 | xt) = N(μθ(xt, t), Σθ)。β 很小时，反向的形状也是高斯（Sohl-Dickstein 等）。最大化似然不能直接算，改为优化上界：

E[−log pθ(x₀)] ≤ Eq[ −log p(xT) − Σt≥1 log ( pθ(xt−1|xt) / q(xt|xt−1) ) ] =: L

把它重新整理（附录 A，每一步只是贝叶斯公式），得到一串可算的 KL：

L = DKL(q(xT|x₀) ‖ p(xT))（LT）+ Σt>1 DKL(q(xt−1|xt, x₀) ‖ pθ(xt−1|xt))（Lt−1）− log pθ(x₀|x₁)（L₀）

关键是：已知 x₀ 时，真实的倒退一步 q(xt−1|xt, x₀) 也是高斯，有公式。

μ̃t = [√ᾱt−1 βt / (1 − ᾱt)] x₀ + [√αt (1 − ᾱt−1) / (1 − ᾱt)] xt，　β̃t = βt (1 − ᾱt−1) / (1 − ᾱt)

因为 βt 固定，LT 是常数，可以不管。方差 Σ 也固定成 σt²I（βt 和 β̃t 效果相近）。于是每项 KL 只剩均值之差：Lt−1 = E[ ‖μ̃t − μθ‖² / (2σt²) ] + C。

关键一步：预测噪声

直接让网络预测 μ̃ 是可以的，但论文做了一个代换。

把 x₀ 用 ε 替换
  1. 由 xt = √ᾱt x₀ + √(1 − ᾱt) ε，得 x₀ = (xt − √(1 − ᾱt) ε) / √ᾱt。
  2. 代入 μ̃t 并整理：μ̃t = (1/√αt)( xt − βt ε / √(1 − ᾱt) )。
  3. xt 网络已经看到了，唯一不知道的就是 ε。所以让网络预测 ε：μθ = (1/√αt)( xt − βt εθ(xt, t) / √(1 − ᾱt) )。
  4. 两个 μ 相减，xt 约掉，只剩 ε − εθ 乘一个系数：
Lt−1 − C = E[ βt² / (2σt² αt (1 − ᾱt)) · ‖ε − εθ(√ᾱt x₀ + √(1 − ᾱt) ε, t)‖² ]

这个公式把两条路线连起来：它和去噪分数匹配（NCSN）的损失形式相同，采样又类似退火 Langevin 动力学。论文认为这个等价关系是主要贡献之一。

代入算一下（t = 100，论文噪声表）
  1. β₁₀₀ ≈ 0.0021，ᾱ₁₀₀ ≈ 0.90。如果 x₀ = 1，ε = 1：x₁₀₀ = √0.90 + √0.10 = 0.949 + 0.316 = 1.265。
  2. 如果网络猜对了 ε = 1：μ = (1/√0.9979)(1.265 − 0.0021 × 1 / 0.316) ≈ 1.260。
  3. 也就是每步只挪一点点。1000 步累积起来才从噪声变成图。

两个算法

训练（算法 1）采样（算法 2）
1. 取一张图 x₀
2. 随机取 t（1 到 T）
3. 取 ε ~ N(0, I)
4. 对 ‖ε − εθ(√ᾱt x₀ + √(1 − ᾱt) ε, t)‖² 做梯度下降
5. 重复 		1. xT ~ N(0, I)
2. t = T, …, 1：
　z ~ N(0, I)（t = 1 时 z = 0）
　xt−1 = (xt − βt εθ / √(1 − ᾱt)) / √αt + σt z
3. 输出 x₀

注意每步还要加一点噪声 σt z。这是 Langevin 的特点：既往好的方向走，也保留随机性。

简化目标为什么更好

Lsimple = Et, x₀, ε[ ‖ε − εθ(√ᾱt x₀ + √(1 − ᾱt) ε, t)‖² ]

就是把系数扔了。这样不再是严格的下界，而是“加权的下界”。按这个噪声表，真实系数在 t 小时很大，扔掉后等于降低了很小 t 的权重，让网络集中精力学难的（噪声大的）部分。结果是：似然变差，图变好。

系数有多大差别（σ² = β）
  1. 原系数 = β / (2 α (1 − ᾱ))。
  2. t = 1：1 − ᾱ₁ = 0.0001，β = 0.0001，系数 ≈ 0.5。
  3. t = 100：系数 ≈ 0.0021 / (2 × 0.998 × 0.10) ≈ 0.01。
  4. t = 1000：系数 ≈ 0.02 / (2 × 0.98 × 1) ≈ 0.01。t = 1 的权重比其他大 50 倍。

实现细节：U-Net（来自 PixelCNN++）、组归一化、时间用 Transformer 的正弦编码加到每个残差块、16×16 处自注意力。CIFAR10 模型 3570 万参数，每秒 21 步，10.6 小时训练 80 万步。

压缩的视角

把变分下界看成信息量：L₁+…+LT 是码率，L₀ 是失真。最好的模型 1.78 + 1.97 = 3.75 比特/维，均方根误差只有 0.95（0–255 刻度）。也就是说，一半以上的码长用在了人看不出的细节上。

论文定义了一种渐进编码（算法 3、4），用的是最小随机编码这种理论方法。接收方任何时候都能估计 x̂₀ = (xt − √(1 − ᾱt) εθ) / √ᾱt。图 5 显示失真在低码率时下降很快。

也可以这样看：如果前向过程不是加噪声，而是逐个遮掉像素，那么训练扩散模型就是训练自回归模型。所以高斯扩散可以看作一种“比特顺序更一般”的自回归。这是论文的推测。

渐进生成和插值

  • 先轮廓后细节：生成时看 x̂₀，大尺度特征先出现，细节最后。
  • 同一中间状态：从 t = 750 分叉，生成的脸共享性别、发色、姿势等；从 t = 250 分叉，只差细节。说明高层属性早就定了。
  • 插值：先把两张图加噪到 t = 500，线性混合，再去噪。比在像素上混合自然，能改姿势、肤色、发型，但换不了眼镜。t 越大变化越粗。

读结果时要注意的地方

  • FID 的选取：附录 B 写明，分数取训练过程中 FID 最小的点，而 FID 是对训练集算的，这会有一定选择偏差。测试集上是 5.24。
  • 只训一次：“Final experiments were trained once”。表中的 ± 是 IS 的采样误差，不是训练随机性。
  • 超参数在 CIFAR10 上调：其他数据集直接迁移。
  • 似然不好：3.75 比特/维，稀疏 Transformer 是 2.80。论文诚实地说“不具竞争力”。
  • 公式小错：§4.4 的插值式写成 x̄t = (1 − λ)x₀ + λx′₀，从上下文看应该是 xt 和 x′t。
  • 慢：1000 步。CIFAR 一批 256 张要 17 秒；256² 一批 128 张要 300 秒。
  • “和 ProgressiveGAN 相近”：主要依据 LSUN，CelebA-HQ 的样本只有图，没有 FID。

第一轮看起来不对：论文说预测 ε 最好，这里却只有约六成合格，预测 x₀ 几乎全合格。我们没有直接写结论，而是猜了一个原因：普通 MLP 没有从输入到输出的直连，要预测 ε 就得把 64 维的噪声几乎原样“抄”过去，128 单元可能太窄；预测 x₀ 只需要输出 10 个字形之一，容易得多。所以只改宽度，又跑了一轮：

这组结果怎么读（诚实版）：
  • 第一轮差点把人带偏。128 单元时，预测 ε 只有 60% 合格，预测 x₀ 有 100%，正好和论文的做法反过来。论文一句括号里说预测 x₀ 在早期实验里样本更差，所以我们先怀疑自己的实验。
  • 加宽后，猜测得到支持。只把宽度改成 256，预测 ε 的合格率升到 83%，种子 0 的 Fréchet 距离从 59.4 降到 3.0。这说明窄网络确实拖了 ε 的后腿。但这是相关证据，不算证明“抄噪声”就是唯一原因。
  • 两把尺子给出不同答案。按“好样本”，x₀ 仍然赢（99% 对 83%）。按论文用的那类分布距离，ε 略好（ε 3.0 和 2.3，x₀ 3.4 和 3.2），差距很小，只有 2 个种子，不能算复现了论文。
  • 为什么会这样？看“平均错像素”。真实数据有 2% 的翻转像素，平均错 1.3 个。x₀ 版只错 0.2 个，比真实数据还干净，等于把这些翻转抹掉了；ε 版错 3.1 个，又太脏。“好样本”只奖励干净，所以偏向 x₀。这是我们自己定的指标的偏见。
  • 简化目标和预测方式的结论，和论文方向一致。宽 256 时，预测 ε 的简化目标比变分界权重合格率高（83% 对 65%），Fréchet 距离的两种子均值也更小（2.7 对 5.3）。预测 μ̃ 最差（39%）。不过论文里“预测 μ̃ + 无权重 MSE”是不稳定，我们这里只是变差，没有崩。
  • Fréchet 距离很容易被少数坏样本拉高。种子 0 的变分界版里，有样本的像素值冲到了 35（正常范围是 −1 到 1），距离就是 7.6；种子 1 最大只有 8，距离是 3.0。第一轮种子 0 的 59.4 大概也是这样（第一轮没记录最大值，这只是猜测）。
  • 我们以为截断会有用，结果没有。把每步估计的 x̂₀ 截到 [−1, 1] 后，ε 版合格率没升，Fréchet 距离还从约 2.7 变成 6.5。所以截断挡不住这里的问题。
  • 比特花在哪：和论文图 5 同一个形状。加宽版一共约 3.55 比特/维的码率，最后 10 步花掉 71%，这时误差只从 0.14 降到 0.04。也就是大部分比特都在描述细微之处。图里的码率不含 L₀：我们的数据是连续处理的 ±1，没有做论文那种离散化，L₀ 是负数，不能和论文的 3.75 比特/维直接比。
  • 没有重跑的部分。上表里的步数和噪声表比较都只在 128 单元下跑过。那时 T = 50、T = 1000 都没有明显好过 T = 200，二次增长的表略好，但网络窄、差距小，只能算线索。

局限和争议

  • 慢：1000 次网络调用。这是后面很多工作的出发点。
  • 似然：见上。

一页总结

  • 一个直觉：小步走，就能倒着学。
  • 一个公式：xt = √ᾱt x₀ + √(1 − ᾱt) ε。
  • 一个目标：‖ε − εθ‖²。
  • 一个取舍：不做严格下界，换来更好的图。
  • 一个弱点：1000 步。
