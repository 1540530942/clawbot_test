Mamba：会选择的记忆Mamba: Linear-Time Sequence Modeling with Selective State Spaces

注意力好用，但序列长度翻倍，计算量翻四倍，还要把全部历史存着。状态空间模型（SSM）只保留一个固定大小的状态，序列再长每步也只算一次，可它处理语言一直不行，因为它对每个词一视同仁。Mamba 只改了一点：让“记多少、忘多少”由当前的输入决定。这样一来，就有了和 Transformer 差不多的语言成绩，同时计算量随长度线性增长。

边听边记的人

两个记笔记的学生

老师讲一小时。学生甲录下全部声音，每次回答问题都重听一遍。答得准，但很慢，录音也越来越大。这像注意力。

学生乙只有一张便签，容量固定。他每听一句就按相同的比例擦掉旧内容、写上新内容。很快，但重点和废话待遇相同。这像线性状态空间模型。

学生丙也只有一张便签，但他会判断：“这句重要，写下来；这句是废话，不理。”这就是 Mamba。

状态空间模型

h′(t) = A h(t) + B x(t)，　y(t) = C h(t)

把连续时间离散化（零阶保持）：

ht = Ā ht−1 + B̄ xt，　yt = C ht Ā = exp(ΔA)，　B̄ = (ΔA)⁻¹(exp(ΔA) − I) ΔB
ht
状态，大小 N（每个通道）。不管序列多长，大小不变。
A
对角矩阵，决定每个状态分量衰减多快。
Δ
时间步长。Δ 大：这一步“过了很久”，旧状态衰减得多，新输入占比大。Δ 小：旧状态基本保留。
算一步（一个状态分量，A = −1，B = 1，C = 1）
  1. Δ = 0.1：Ā = e⁻⁰·¹ ≈ 0.905，B̄ = (e⁻⁰·¹ − 1)/(−1) ≈ 0.095。
  2. h 原来是 2，输入 x = 10：h 新 = 0.905 × 2 + 0.095 × 10 = 2.76。旧的基本保留。
  3. Δ = 3：Ā ≈ 0.05，B̄ ≈ 0.95。h 新 = 0.05 × 2 + 0.95 × 10 = 9.6。几乎被新输入取代。

如果所有参数不随时间变化（线性时不变，LTI），把递推展开，就是一个卷积：

y = x * K̄，　K̄ = (CB̄, CĀB̄, …, CĀkB̄, …)

这种对偶性很有用：训练时用快速傅里叶变换算卷积，推理时用递推。但这也是软肋。

为什么不会读文字

论文认为，序列建模的基本问题就是把上下文压缩进一个小状态：

  • 注意力根本不压缩（要存全部历史，推理时的 KV 缓存），所以好用但慢。
  • RNN 状态固定，所以快，但效果取决于压缩得好不好。

LTI 模型对每个输入用相同的规则，压不好。两个合成任务暴露了这一点：

  • 普通复制：输入输出间隔固定，一个合适长度的卷积核就能解。
  • 选择性复制：数据词之间间隔随机。LTI 模型的卷积核不会变，于是不行。
  • 归纳头：见过 “Harry Potter”，下次看到 Harry 就预测 Potter。这被认为和大模型的上下文学习密切相关（Olsson 等）。

选择：让参数依赖输入

改动只有几行（算法 2）：

Bt = sB(xt)，　Ct = sC(xt)，　Δt = softplus(p + sΔ(xt))
sB、sC
线性投影。决定这个词怎样写入状态、怎样从状态读出。
sΔ
投影到 1 维再广播到所有通道：如果这个词该被忽略，所有通道都该忽略。
A
不变。因为它只通过 ΔA 起作用，Δ 选择了就够了。

但这样一来，参数随时间变化，不再等价于卷积。之前所有结构化 SSM 都是时不变的，就是因为这个效率限制。这正是论文要解决的第二个问题。

选择带来三种效果（§3.5.2）：可以跳过无关内容（比如口语里的“嗯”）；能重置状态，让更长的上下文不至于带来噪声；在文档边界可以清零。

和门控 RNN 的联系

定理 1 很漂亮：取 N = 1，A = −1，B = 1，Δt = softplus(Linear(xt))，代入零阶保持公式：

推导
  1. Āt = exp(−Δt) = 1 ÷ (1 + exp(Linear(xt)))，因为 softplus(z) = ln(1 + ez)。
  2. 这正好是 σ(−Linear(xt)) = 1 − σ(Linear(xt))，记 gt = σ(Linear(xt))。
  3. B̄t = 1 − Āt = gt。
  4. 于是 ht = (1 − gt) ht−1 + gt xt。这就是经典 RNN 的门。

这解释了为什么选 softplus。作者还专门澄清：现在常说的“门控”常常指逐元素相乘（比如 GLU、H3 的门），这并不沿序列方向影响信息传播，所以不能解决选择性复制。论文用“选择”这个词，就是为了区分（附录 A）。

和 LSTM 比有什么不同？状态扩大了 N 倍（N = 16），而且 B、C 也可选择；这些后面消融可以看到很重要。

硬件感知算法

卷积不能用了，只能递推。递推有两个麻烦：一步一步算不能并行；状态要存 (B, L, D, N) 这么大，比输入输出大 N 倍。

算一算运算量
  1. 递推 O(BLDN)，卷积 O(BLD log L)。序列长、N 不大时，递推运算量反而可以更少。
  2. 比如 L = 2¹⁶，log L = 16，而 N = 16，两者相当。而递推的常数还更小。
  3. 所以问题不在运算，而在内存读写。这正是第 16 期的思路。
  • 内核融合：只把 Δ、A、B、C 读到 SRAM，在芯片上做离散化和递推，再把 (B, L, D) 大小的结果写回显存。读写减少 N 倍。论文报告比标准实现快 20 到 40 倍。
  • 并行扫描：递推可以按“前缀和”的方式分治并行（Blelloch 1990）。
  • 重算：反向传播时不存中间状态，而是重算。

结果：内存和 FlashAttention 差不多。两个 Mamba 块约 32 字节每词块，和一个注意力层加 MLP 相当。Tri Dao 正是 FlashAttention 的作者。

结构

不再交替放注意力块和 MLP 块，而是把两者并成一个块重复。E = 2：每块参数约 3ED² = 6D²，两块 12D²，正好等于 Transformer 的注意力和 MLP 一层。D 和 N 决定状态大小，而 SSM 本身的参数很少。激活函数 SiLU，这样门部分就是 SwiGLU。

默认实数状态。论文的猜测是：复数对连续信号（音频、视频）有帮助，对离散数据（文字、DNA）没有。它只在音频上切换回复数。

读结果时要注意的地方

  • 规模：语言实验最大约 1.3B，零样本到约 3B。论文自己说，是否在 7B 以上仍然成立还不知道（§5）。
  • 归纳头的比较：Mamba 1e-3 学习率 20 万步；RoPE、xPos 40 万步；H3、Hyena 8 万步后不再改善。不算不公平，但条件并不完全一样。每个模型取两种学习率的较好者。
  • “5 倍吞吐”：摘要说 5 倍，§4.5 说 4–5 倍。还提到 6.9B 未训练的模型的吞吐。这是纯速度比较。
  • “两倍大小”：表 1 中 Mamba-790M 胜 Pythia-1.4B，但 Mamba-370M（平均 50.0）低于 Pythia-1B（51.9）。“一般”这个词要注意。其中比较对象的上下文长度也不同（RWKV 1024）。
  • 缺失：RWKV、RetNet 在 8k 序列上因为实现问题没有完整结果。
  • 音频换成复数：这是全文唯一的切换，也是“没有免费午餐”的证据。选择机制可能损害连续信号。
  • 下游：论文明说微调、量化、RLHF 等生态是否适用，都还未知。

亲手试：门怎么开关

我们用 NumPy 从头实现了选择性 SSM（梯度和数值微分对比过），和线性时不变 SSM、小注意力模型比较两个合成任务。为了能跑，规模很小：2 层，32 维，N = 4，2 个种子。归纳头训练 1000 步；选择性复制第一轮 1000 步没训练够，又加到 6000 步。这是玩具实验。第一轮脚本和加长版都可以下载。

这组结果怎么读（诚实版）：
  • 第一轮选择性复制没训练够。1000 步时，选择性 SSM 在训练长度上只有 53% 和 74%，还不如注意力的 91%，看起来和论文相反。但它的损失还很高。我们把这个任务加到 6000 步，第一轮的数字留在下面的表里。
  • 练够之后，三个模型在训练长度上都接近 100%，差别在外推。测试长度翻倍到 64，选择性 SSM 还是 100%，线性时不变只剩 26%，注意力只剩 52%。方向和论文一致。
  • 但外推没有论文那么神。再长就开始掉：长度 256 时两个种子是 79% 和 38%，长度 1024 时是 31% 和 13%（随便猜约 11%）。而且两个种子差得不小。论文的 Mamba 是从 2⁸ 外推到 2²⁰，我们的小模型远远达不到。
  • 门真的在开关。我们量了种子 0 第一层的 Δ：数据词上平均 0.161，噪声词上平均 0.010，差约 17 倍。也就是遇到要记的词才写入，遇到噪声几乎不动，这正是论文说的“选择性”。下面的小组件可以亲眼看。
  • 归纳头的结果最干净。1000 步时选择性 SSM 在 16 到 64 长度基本全对，512 时两个种子是 59% 和 100%。注意力只在训练长度 16 上全对，超过就掉（32 时 55%）。线性时不变连训练长度都只有 22%；这一项没有加长，所以只能说 1000 步内没学会。
  • 给注意力一点公道。我们的注意力用的是可学习的位置向量，训练时没见过的位置基本是随机的，这对外推很不利。论文也提到不同位置编码有差别（xPos 略好）。它的参数还比另外两个多，约 52K 对 13K。所以“注意力外推差”不能全怪注意力机制本身。
  • 没有测的。没有语言模型、困惑度、吞吐和速度比较，也没有用论文的全部结构。这些只能看前面引用的论文数字。

局限和争议

  • 规模未验证：论文的第一点。
  • 没有免费午餐：连续信号上可能反而变差。
  • 固定状态的本质：有限状态终究要丢信息。需要精确回忆很长历史时，注意力未必输。玩具实验测不到这一点。
  • 生态：大家投入的 Transformer 优化（量化、缓存、微调）不能直接套用。
  • 解释力：“压缩”解释很有吸引力，但对真实语言的证据主要来自消融，不是机理分析。

一页总结

  • 一个观点：序列建模就是压缩上下文。
  • 一个改动：Δ、B、C 依赖输入。
  • 一个联系：Δ 的选择就是 RNN 的门。
  • 一个算法：融合、并行扫描、重算。
  • 一个提醒：只测到 1B 量级；大规模是否成立尚未证明。
