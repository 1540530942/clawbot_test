这篇论文在说什么

第 1 期讲过，Transformer 读到一个字时，要回头和前面每个字都比较一次。一篇 1000 字的文章要比 100 万次，10000 字要比 1 亿次。文章长 10 倍，计算量就涨 100 倍。第 16 期的 FlashAttention 让它算得更快，却没有减少这个数量。

2023 年底，Albert Gu 和 Tri Dao（就是 FlashAttention 的作者）提出 Mamba：用一个笔记本代替“翻遍全书”，计算量只和文章长度成正比，同时做到和 Transformer 差不多的水平。它是第一个真正达到这个水平的线性时间模型。

旧方法的问题

更早的 RNN（第 25 期会讲）已经有“笔记本”了，读新字时只更新笔记，计算量也随长度线性增长。问题是它的笔记本容易忘事，还很难并行训练。所以 Transformer 才取代了它。

生活中的类比

你在看一部很长的连续剧。Transformer 式的观众，每看一集就把前面所有集重看一遍，记得清楚但太慢。RNN 式的观众只靠记忆，看到后面就把开头忘了。最聪明的观众边看边记笔记，遇到关键情节认真写，路人甲的镜头就略过。Mamba 要学的就是这种观众。

核心思想：会挑重点的笔记本

Mamba 的基础叫状态空间模型（SSM）。先看最简单的离散形式：

ht = A · ht−1 + B · xt
yt = C · ht
ht
读完第 t 个字后的笔记本（一串数）。
xt
第 t 个字（一串数）。
A
保留多少旧笔记。0 表示全部擦掉，1 表示全部保留。
B
这个新字写进笔记多少。
yt
这一步的输出。C 决定从笔记里读出什么。
A = 0.5，B = 1，输入依次是 2、0、0
  1. 开始 h = 0
  2. 第 1 个字：h = 0.5×0 + 1×2 = 2
  3. 第 2 个字：h = 0.5×2 + 1×0 = 1
  4. 第 3 个字：h = 0.5×1 + 1×0 = 0.5
  5. 可以看到，这个信息每过一个字就少一半。

老版本的 SSM 里，A 和 B 对每个字都一样，也就是“无论读到什么，都一样地记、一样地忘”。这太笨了。Mamba 最关键的一步叫选择性：让 B、C 和一个叫 Δ 的量都由当前这个字决定。

B = B(xt)，C = C(xt)，Δ = Δ(xt)

Δ 可以理解成“这个字有多值得停下来看”：Δ 越大，笔记更新越多，旧内容也更快被替换。Δ 接近 0，这个字几乎被跳过。论文的消融也显示，Δ 是这三个里最重要的。

动手试试：笔记本怎么记、怎么忘

笔记本 h 只有一个数，每读一个字更新一次：h = a × h + b × x。这句话里只有“猫”和“鱼”重要，x 代表它们带来的信息。选择“选择性”模式时，模型按字决定记多少；关掉就是老方法。

组件里的 a、b 是我为了演示手动设的。真正的模型中，这些值是根据每个字计算出来的，而且 h 是很长的一串数，每个位置都有自己的 Δ 和 A。

拼成完整系统

光靠更新笔记还有个问题：一个字一个字算，训练时没法并行。论文用了几个工程技巧：

  • 并行扫描：一种叫 scan 的算法，可以把这种一步接一步的计算拆开并行，比 PyTorch 的标准实现快 20 到 40 倍。
  • 放在“书桌”上算：把笔记本的计算放在 GPU 的 SRAM 里，不写回 HBM，这正是第 16 期 FlashAttention 的思路。
  • 省 KV cache：Transformer 生成文字时要保存之前所有字的 K、V。Mamba 只存笔记本，每一步耗时相同。

块的结构也和第 19 期 LLaMA 相似：门控的 SiLU 激活、残差连接，两个 Mamba 块叠在一起，参数大约等于一个 Transformer 层的 12D²。

  • 生成速度：和相近规模的 Transformer 相比，吞吐量约 5 倍。

影响和局限

影响：此后出现了大量 Mamba 变体（Vision Mamba、医学图像、Jamba 等），状态空间模型重新成了 Transformer 的竞争者。它提醒人们：Transformer 并不是唯一的答案。

局限：

  • 规模还不够大。论文只做到约 28 亿参数，比当时领先的开源模型小得多。
  • 未必一直胜出。选择性对文字和 DNA 这类离散数据有利，音频波形这类连续数据就不一定。
  • 今天的主流还是注意力。到现在，多数顶尖大模型仍基于 Transformer，这个方向值得关注，但还没有替代。这一点属于我的背景判断。
  • “笔记本”有容量限制。只保留状态，本质上要压缩信息；精确引用很久以前的内容时可能不如注意力。这也是我的说明，不是论文结论。

和你的机器人的关系：这类模型其实很适合端侧：每一步耗时固定，内存也固定，非常适合传感器流。IMU、超声波这种一直涌来的数据，Transformer 要越存越多，而笔记本式模型不需要。如果要做小型的行为预测模型，这个方向值得试试。

一句话总结：不翻遍全书，只靠一本会挑重点的笔记本，计算量就从 N² 降到了 N。
