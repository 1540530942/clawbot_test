ELMo：词的意思要看句子Deep contextualized word representations

word2vec 给每个词一个固定向量，所以 bank（银行）和 bank（河岸）只能共用一个。这篇论文的回答是：词向量应该是整句话的函数。它先在大量文本上预训练一个双向语言模型，再把模型每一层的表示都交给下游任务，让下游自己学配比。这几乎不需要改动原模型，却让六个任务全部刷新了纪录。

一个词，很多意思

同一个“打”

“打电话”“打篮球”“打酱油”“打人”。中文的“打”有几十种用法，你一听整句就知道是哪个。词典给你的却是同一个字。word2vec 也一样，把所有用法平均成一个向量。

ELMo 要做的是：让“打”在“打篮球”里的向量靠近“玩”，在“打电话”里靠近“拨”。向量不再查表，而是读完句子后算出来。比喻是我们编的。

双向语言模型

前向：p(t1, …, tN) = ∏ p(tk | t1, …, tk−1) 后向：p(t1, …, tN) = ∏ p(tk | tk+1, …, tN) 目标：Σk [ log p(tk | 左边; Θx, Θ→, Θs) + log p(tk | 右边; Θx, Θ←, Θs) ]

两个方向分别预测下一个词和上一个词。它们共用词表示 Θx 和输出层 Θs，LSTM 各用各的。这里的关键是完全不需要标注：普通文本自己就是答案。

为什么预测词能学到词义
  1. 要预测 “the fish swam near the bank of the ___” 的下一个词。
  2. 模型要给 river 高概率，给 money 低概率。
  3. 所以读到 bank 时，状态里必须已经装了“和水有关”的信息。
  4. 这个状态就是我们要的上下文相关向量。这是直观解释，不是论文的证明。

ELMo 公式

每个词有 2L + 1 个表示，这里 L = 2：词层一个，两个双向层各一对。拼接后是 3 层：

Rk = { hk,jLM | j = 0, …, L }，　hk,j = [ h→k,j ; h←k,j ] ELMoktask = γtask Σj=0L sjtask hk,jLM
sj
softmax 归一化的层权重，由下游任务学习。不同任务不同。
γ
整体缩放。补充材料说它很重要：没有它，只用最后一层时 SNLI 远低于基线，SRL 直接训练失败。
算一个（2 维的假向量）
  1. h₀ = (1, 0)，h₁ = (0, 2)，h₂ = (2, 2)。
  2. 层权重原始分 (0, 1, 0)，softmax 后 s = (0.21, 0.58, 0.21)。
  3. Σ s h = (0.21 + 0 + 0.42, 0 + 1.16 + 0.42) = (0.63, 1.58)。
  4. γ = 2：ELMo = (1.26, 3.16)。

怎么接进下游模型

  1. 冻结预训练的语言模型。
  2. 把 ELMo 向量拼到原来的词表示上：[xk ; ELMok]，送入任务 RNN。
  3. 某些任务（SNLI、SQuAD）在 RNN 输出处再加一份：[hk ; ELMok]，用另一组权重。
  4. 适度 dropout，有时加正则 λ‖w‖²，把层权重拉向平均。λ = 1 差不多就是平均；λ = 0.001 让它自由变化。

冻结是它和 Dai、Le 等微调方法的关键区别：下游数据少时，模型可以小，但仍用到一个很大的语言模型。

“相对误差减少”怎么算（以 SQuAD 为例）
  1. 基线 81.1，错误部分是 100 − 81.1 = 18.9。
  2. 加 ELMo 后 85.8，错误部分 14.2。
  3. 减少比例 (18.9 − 14.2) ÷ 18.9 = 24.9%。
  4. 注意 F1 不严格是准确率，这只是惯用算法。
  • 问答 SQuAD：基线是加了自注意力的 BiDAF。4.7 分的提升远大于 CoVe 的 1.8 分。11 个模型集成 87.4，投稿时榜首。
  • 文本蕴含 SNLI：基线 ESIM。5 模型集成 89.3。
  • 语义角色标注：重新实现 He 等的 8 层交错 biLSTM，单模型 84.6，超过此前的集成 83.4。
  • 指代消解：70.4，超过此前的集成 68.8。
  • 命名实体：92.22，和 Peters 等的差别主要是用所有层。
  • 情感分类：把 CoVe 换成 ELMo，提升 1.0。

消融：哪些设计真的有用

从基线到“只用最后一层”，跳了一大步（SQuAD +3.9）。再用所有层，又多几个 0.1。所以贡献最大的是上下文表示本身，“所有层”这点是相对小的额外提升。CoVe 的趋势相同，提升更小。

每一层学到了什么

GloVe 中 play 的近邻是 playing、game、games、played，大多和体育有关。biLM 能分开：“Chico Ruiz made a spectacular play”找到的是体育比赛里的句子，“signed to do a Broadway play”找到的是戏剧里的句子。

论文用两个小测试看每一层：词义消歧（每个词义取平均向量，1-近邻）和词性标注（线性分类）。

  • 词义：高层更好（69.0 对 67.4）。
  • 词性：低层更好（97.3 对 96.8）。
  • biLM 都胜 CoVe。CoVe 在词义上甚至没赢“总选第一义项”的基线（65.9）。

这和计算机视觉里低层学边缘、高层学物体的直觉相似（类比是我们加的）。这也解释了为什么要把所有层交出去。

读结果时要注意的地方

  • 数字不一致 1：§1 说“最多减少 20%”，§4 说“6–20%”，但表 1 中 SQuAD 是 24.9%，NER 是 21%。
  • 数字不一致 2：§4 说 SQuAD 比基线高 4.7，补充材料 A.4 说 4.2。
  • 提升是相对自家基线：相对误差的基线是作者自己的实现，常低于当时最好（SQuAD 81.1 比 84.4，SNLI 88.0 比 88.6，NER 90.15 比 91.93）。和“当时最好”比，提升小得多：SNLI 只有 0.1。
  • SNLI 的“新纪录”：88.7 ± 0.17 对 88.6，在误差范围内。
  • 单次运行：只有 NER、SST、SNLI 报告了多种子，其他任务一个数字。
  • 配置逐任务调：用不用层归一化、λ 取多少、加在哪里都因任务而异。比如 SQuAD 不加层归一化、λ = 0；NER λ = 0.1。开发集上选的。
  • “simply adding”：多数任务用了在其训练集上微调过的语言模型，不是纯粹现成的。
  • 个别数字的归属：§5.1 中 88.2→88.7 和 82.2 是在讲 CoVe，不要和表 2 混。
  • “competitive”：词性 97.3 低于 97.8，词义 69.0 低于 70.1。论文的用词是竞争，不是超过。

亲手试：bank 是哪个 bank

我们用 NumPy 写了完整的迷你版：双向 2 层 LSTM（32 维）、共享词向量和输出层、层间残差，在合成语料上只用文本训练 800 步。语料里有 5 个多义词：bank（金融/河岸）、bat（球棒/蝙蝠）、play（戏剧/玩耍）、fly（飞/苍蝇）、light（灯/轻）。然后冻结，只用线性分类器预测词义和词性。没有字符卷积，语料也是手写模板，规模很小。这是玩具。完整脚本在这里。

这组结果怎么读（诚实版）：
  • 论文的核心现象出现了：只用词向量时，词义准确率卡在一半上下（1000 句时 49.9%）。这是硬上限：同一个词永远是同一个向量，只能选一个义项。换成 biLM 第 1 层，100 句就到 98.7%，300 句以上都是 100%。
  • 标注少的时候也有优势：10 句标注时第 1 层 55.7%，词向量 39.3%；30 句时差距更大，86.3% 对 50.8%。语言模型一个标注都没看过，语境信息是只读文本学来的，下游分类器也只是线性的。这正是半监督的意思。
  • 词性也提升，但幅度小：1000 句时词向量 97.0%，第 1 层 100.0%。大多数词只有一个词性，词向量本来就不错。
  • “高层管词义、低层管词性”没有复现：论文表 5、表 6 里这个差异很清楚。我们这里两层都太快饱和，分不出高低。用论文的 1-近邻方法，第 1 层对第 2 层，两个种子分别是 96.8% 对 93.8%、90.3% 对 92.7%，方向还相反。所以这个玩具对分层假说既不支持也不反驳。
  • 学到的权重不能过度解读：1000 句时词义任务给第 1 层的权重是 0.99 和 0.95，说明一层已经够用。词性任务里两个种子差别很大（第 1 层 0.99 和 0.03），说明这里没有稳定的偏好。
  • 100% 不要当真：测试句和训练句来自同一批手写模板，语料很小，语言模型的困惑度低到约 1.5，接近背下了语料。满分只说明任务简单，不说明它能读懂没见过的句型。论文的 biLM 用 1B Word Benchmark 训练，前后向平均困惑度是 39.7。
  • 规模：2 个种子，800 步，隐藏层 32 维。只看方向，不看具体数字。

时间工作关系

BERT 论文的结果也比较了把最后四层加权（第 2 期），和这里的“所有层”思路相通。名字也有一段玩笑：ELMo、BERT 都是《芝麻街》的角色（背景知识）。

局限和争议

  • 慢：每个词要跑大 biLSTM，上下文依赖计算量大。
  • 只读不改：冻结模型，下游无法调整深层。后来的 BERT 走向全模型微调。
  • 评测范围：都是当时的标准集。

一页总结

  • 一句话：词向量应该是整句的函数。
  • 一个公式：γ Σ sj hj，下游学配比。
  • 一个发现：低层偏语法，高层偏语义。
  • 一个提醒：大头是上下文本身；相对误差比的是自家基线。
