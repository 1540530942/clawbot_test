Flamingo：看几个例子，就会新任务Flamingo: a Visual Language Model for Few-Shot Learning

教新任务，能不能像考试看例题一样，只放几个例子？Flamingo 往冻结的语言模型里插入几层看图的交叉注意力，再读 4300 万个图文交错的网页。不用微调，只靠提示，就在多项任务上追上了微调过的最好模型。

这篇论文在说什么

教孩子认新东西，给他看两三张图就够了。AI 呢？传统方法要收集几千张图，再训练一次。GPT-3 已经证明，文字任务可以靠几个例子解决。图片能不能也这样？

2022 年，DeepMind 的 Flamingo 把这件事做成了：提示里放几个“图 + 文字”的例子，模型就接着做，不用微调。它早于第 20 期的 LLaVA，是这方向的重要里程碑。Flamingo 和 Chinchilla 一样，也是动物的名字（火烈鸟）。

旧方法的问题

在此之前，CLIP（第 10 期）能做零样本分类，但不能写字；图像描述模型只能做描述；每种新任务都要重新训练。人们希望一个模型能同时做好描述、问答和各种看图任务，也不用微调。

生活中的类比

你在考场上遇到一种没见过的题型，卷子上恰好附了几道解析好的例题。看完你就明白怎么答了。Flamingo 就是这样的考生，例题里同时有图和字。

核心思想：往语言模型里插几层“看图”

三个部件：

  • 视觉编码器（NFNet-F6）：现成的，冻结，把图变成很多特征。
  • Perceiver Resampler：不管有多少特征（视频帧数不同），都压成 64 个视觉 token。这样下游就能用固定的成本。
  • 门控交叉注意力：插在语言模型的层之间。每个字经过这里时，都能看看图。

交叉注意力和第 1、32 期是一回事：Q 来自文字，K、V 来自图。语言模型用的就是第 15 期的 Chinchilla：70 亿参数的 7B 版和 700 亿参数的 70B 版，加上视觉部分就是 Flamingo-9B 和 80B。

数学：门控从 0 开始

把新层直接插到训练好的语言模型里，一开始它们输出的是随机的东西，会把语言模型的结果搞坏。论文的解决办法很漂亮：

y = ytext + tanh(α) · 交叉注意力结果
α
可以训练的一个数，初始为 0。
tanh
把任何数压到 −1 到 1 之间的函数。tanh(0) = 0。
ytext
原来语言模型的结果。
文本值 5，图像信息 2
  1. α = 0：tanh(0) = 0，y = 5 + 0 × 2 = 5
  2. α = 0.5：tanh(0.5) ≈ 0.462，y ≈ 5.92
  3. α = 2：tanh(2) ≈ 0.964，y ≈ 6.93
动手试试：门控怎么让新层慢慢起作用

输出 = 文本 + tanh(α) × 图像信息。α 从 0 开始，所以刚开始模型和原来的语言模型完全一样。拖动 α，看新层的影响怎么变。

第 12 期的 LoRA 里，B 初始化为 0 也是同样的道理：训练开始时，新增部分完全不起作用，模型不会被破坏。这是个常用的工程小技巧。

数据：像读网页一样读图

训练用了很多“图文交错”的数据：

数据集规模内容
M3W约 4300 万个网页图文自然交错，也就是真实的网页顺序
ALIGN18 亿图片和替代文字配对
LTIP3.12 亿图片和文字配对
VTP2700 万个短视频平均约 22 秒，配文字

为什么 M3W 这么重要？网页里经常是“一张图，一段说明；下一张图，下一段说明”。这和 few-shot 提示的格式一样。模型读网页时，就在练习这种规律。

训练时每条序列最多只放 5 张图，但评测时用到 32 个例子还能继续受益。论文的结论是：在 6 项任务中超过了经过微调的最好成绩（文字和表格的说法不完全一致，一处写 6，一处写 7）。微调后，还能在 5 项任务上刷新最好成绩。

影响和局限

影响：它证明了“语言模型 + 视觉”的路线可行，也开启了今天多模态大模型的路线。GPT-4（第 50 期）和 LLaVA（第 20 期）都走在这个方向上。

局限（论文）：

  • 继承了语言模型的问题。也会胡编、会没有依据地猜。
  • 序列长了会变差。超过训练时的长度，泛化不好。
  • 分类不如专门方法。和 CLIP 这类模型相比分类精度偏低。
  • 对示例敏感。换几个例子结果可能就变了；超过几十个例子，提升也有限。
  • 没有开放。当时没有公开权重，后来才有社区复现。这是背景信息。

和你的机器人的关系：few-shot 对机器人视觉很实用：把几张“我的房间里的充电座、门、障碍物”的照片和说明放进提示，模型就能按你的场景回答，不用重新训练。这种提示要放在云端跑，并注意例子越多，图片 token 也越多，延迟也越大。

一句话总结：把看图能力插进语言模型，再读足够多图文交错的网页，模型就能靠几个例子学会新任务。
